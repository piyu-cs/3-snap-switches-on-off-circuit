# 💡 3-Snap Switching Circuit

A simple electronic lighting control circuit that changes the light state using repeated ON/OFF switch operations (snaps). The circuit cycles through **Dim → Bright → OFF** without requiring additional switches or microcontrollers.

---

## 📌 Project Overview

This project demonstrates a three-state lighting control system using electronic components. Each quick toggle of the power switch changes the operating mode of the lamp.

The sequence is:

1. 🌙 **First Snap** → Dim Light
2. 💡 **Second Snap** → Bright Light
3. ⚫ **Third Snap** → Light OFF

The cycle then repeats from the beginning.

---

## ✨ Features

- Three operating modes
  - Dim Brightness
  - Full Brightness
  - OFF
- Simple hardware implementation
- No microcontroller required
- Designed and simulated using Proteus
- Easy PCB implementation
